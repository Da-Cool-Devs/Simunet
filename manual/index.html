QUICK BUILD

Set up your system

  1. 01

    Choose and build a rack

    Open the Simulator, choose a Standard, GPU-ready, or High-density frame, then select Build Open Rack. Each empty bay can hold one part.

  2. 02

    Add parts to open spaces

    Drag equipment from the list into an open bay. On a phone or tablet, select the equipment first, then tap a bay. Use × to remove a part.

  3. 03

    Prepare the data center

    Turn on Cooling to manage heat, UPS to provide backup power, and Firewall to block attacks. Graphics processors need a GPU-ready rack.

  4. 04

    Put a website online

    Install a Web server and at least one other server, then select Deploy Website. A Backup server is required to run the backup action.

  5. 05

    Keep it running

    Once live, customers arrive and random incidents begin. Watch Live Operations and the log, fix weak spots, and work through the Operator Missions.

HARDWARE GUIDE

What can I install?

Web server Required to deploy

Hosts the website that people visit. Start with this one.

Database server

Stores information used by a website or application.

Storage server

Provides capacity for files and other cloud data.

Backup server Needed for Run Backup

Keeps recovery copies so data can be restored after a failure.

Sign-in server

Checks usernames and decides what each person can access.

Graphics processor

Handles many calculations at once for AI and graphics. It fits GPU-ready racks.

Switch, router & traffic balancer

Connects equipment, directs traffic, and spreads requests across servers.

ROOM CONTROLS

What do these switches do?

Cooling
Removes server heat. Without it, temperature climbs as you add hardware, and above 42°C servers start failing. Uses about 30% extra power.
UPS
Battery backup power. Keeps every server running through a power outage.
Firewall
Filters malicious traffic. Stops traffic floods (DDoS) and blocks password attackers.

Standard racks hold up to 9 parts; High-density racks hold 12. GPU parts need a GPU-ready rack.

LIVE DASHBOARD

Read your system metrics

CPU
How hard your servers are working. Once live, it rises as customers approach your capacity.
Memory
Memory capacity provided by your installed parts.
Storage
Total storage provided by storage-capable servers.
Customers
People using your site. Grows over time; capacity comes from Web servers, boosted by Databases and Load balancers.
Temperature
Safe below 35°C. Turn on Cooling to bring it down.
Power draw
Total kW used, including cooling. Each rack after three adds 10% overhead.
Health
Drops with incidents, overheating, and overload. At 0% the service crashes.

LIVE OPERATIONS / INCIDENTS

What can go wrong, and how to prevent it

IncidentWhat happensYour defense
Power outageThe grid goes down and every server loses power.Enable UPS.
Traffic flood (DDoS)Attackers send huge amounts of junk traffic to overwhelm the site.Enable the Firewall; add a Load balancer for full protection.
Password attackAttackers try to guess customer passwords.Install an Auth server; the Firewall also blocks the attacker.
Disk failureA drive breaks and its data is gone.Install a Backup server and run backups regularly. Backups go out of date after about a minute.
Viral traffic spikeThousands of new visitors arrive at once.Add Web servers, a Database, or a Load balancer to raise capacity.

Use Run drill in the Live Operations panel to trigger any incident on purpose and test your setup.

INTERACTIVE SCENE / CAMERA TO CLOUD

Store a camera photo in the cloud

  1. 01

    Take a picture

    Open the Camera page and use the arrows to choose a view. Select Take picture to add that image to your photo gallery.

  2. 02

    Select the original

    Click a captured photo in Your Photo Gallery. The selected original stays there throughout the simulation.

  3. 03

    Store a cloud copy

    Press Store selected photo to cloud. The JavaScript animation follows a copy from your camera through the network and into a server in the rack.

  4. 04

    Watch it reach the drive

    The copy arrives on the hard drive, the simulated drive meter updates, and the saved copy appears below the animation. Your original photo remains in the gallery.

This is a local educational simulation: photos are generated in your browser and are not uploaded to a real cloud service.
