BEGINNER GUIDE / START HERE

Build your first cloud, one step at a time.

Choose an open rack, add equipment, launch a website, and try the camera scene to watch a photo copy travel into storage.

QUICK BUILD

Set up your system

  1. 01

    Choose and build a rack

    Open the Simulator, choose a Standard, GPU-ready, or High-density frame, then select Build Open Rack. Each empty bay can hold one part.

  2. 02

    Add parts to open spaces

    Drag equipment from the list into an open bay. On a phone or tablet, select the equipment first, then tap a bay. Use × to remove a part.

  3. 03

    Prepare the data center

    Turn on Cooling to manage heat, UPS to provide backup power, and Firewall to stop the practice attack. Graphics processors need a GPU-ready rack.

  4. 04

    Put a website online

    Install a Web server and at least one other server, then select Deploy Website. A Backup server is required to run the backup action.

HARDWARE GUIDE

What can I install?

Web server Required to deploy

Hosts the website that people visit. Start with this one.

Database server

Stores information used by a website or application.

Storage server

Provides capacity for files and other cloud data.

Backup server Needed for Run Backup

Keeps recovery copies so data can be restored after a failure.

Sign-in server

Checks usernames and decides what each person can access.

Graphics processor

Handles many calculations at once for AI and graphics. It fits GPU-ready racks.

Switch, router & traffic balancer

Connects equipment, directs traffic, and spreads requests across servers.

INTERACTIVE SCENE / CAMERA TO CLOUD

Store a camera photo in the cloud

  1. 01

    Take a picture

    Open the Camera page and use the arrows to choose a view. Select Take picture to add that image to your photo gallery.

  2. 02

    Select the original

    Click a captured photo in Your Photo Gallery. The selected original stays there throughout the simulation.

  3. 03

    Store a cloud copy

    Press Store selected photo to cloud. The JavaScript animation follows a copy from your camera through the network and into a server in the rack.

  4. 04

    Watch it reach the drive

    The copy arrives on the hard drive, the simulated drive meter updates, and the saved copy appears below the animation. Your original photo remains in the gallery.

This is a local educational simulation: photos are generated in your browser and are not uploaded to a real cloud service.

ROOM CONTROLS

What do these switches do?

Cooling
Shows cooling units in the room and helps manage heat as you add servers.
UPS
Shows backup power equipment in your data center.
Firewall
Blocks the simulated attack. Without it, an attack can take your deployed site offline.

Standard racks hold up to 9 parts; High-density racks hold 12. GPU parts need a GPU-ready rack.
