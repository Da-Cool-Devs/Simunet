OPERATOR GUIDE / START HERE

Build your first cloud, one step at a time.

A server rack is the cabinet that holds the servers. Build the rack first, install the right servers, then deploy your website from the control panel.

QUICK BUILD

Follow these four steps

  1. 01

    Build a rack

    On the Simulator page, click Build a Server Rack. You need a rack before you can install any servers.

  2. 02

    Install two servers

    Choose Web Server and click Install Server. Then choose another type, such as Database, and install it too.

  3. 03

    Prepare the room

    Turn on Cooling to manage heat and the Firewall to block the attack simulation. UPS represents backup power.

  4. 04

    Deploy your website

    Click Deploy Website. You need at least two servers in total, and one of them must be a Web server.

HARDWARE GUIDE

Which server should I choose?

Web server Required to deploy

Hosts the website that people visit. Start with this one.

Database server

Stores information used by a website or application.

Storage server

Provides space for files and other cloud data.

Backup server Needed for Run Backup

Stores recovery copies. Install one before using the backup button.

Authentication server

Handles user sign-in and access permissions.

ROOM CONTROLS

What do these switches do?

Cooling
Adds cooling units to the room and helps manage heat as you add servers.
UPS
Shows backup power equipment in your data center.
Firewall
Blocks the simulated attack. Without it, an attack can take your deployed site offline.

A rack holds up to 9 servers. Add another rack when the current ones are full.

LIVE DASHBOARD

Read your system metrics

CPU
How much processing capacity your servers are using.
Memory
The memory capacity used by installed servers.
Storage
The total storage provided by your servers.
Customers
Estimated users served after your website is deployed.
