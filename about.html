PROJECT / OVERVIEW

Build the cloud. Learn what keeps it running.

SimuNet is an interactive learning environment that turns cloud computing concepts into hands-on decisions. Start with an empty data center, add real infrastructure components, deploy services, and respond to operational threats.

01 / MISSION

Learn by doing

Explore how physical hardware, networking, compute capacity, storage, reliability, and security work together instead of learning each concept in isolation.

02 / WHAT YOU BUILD

Infrastructure

  • Server racks and compute nodes
  • Cooling and backup power
  • Web, database, storage, backup, and authentication services
  • Firewalls and disaster recovery systems

03 / CORE OBJECTIVES

Operational skills

  • Understand resource limits
  • Plan for high availability
  • Monitor system health
  • Recognize and reduce security risks

Every rack changes the system. Every service creates a new dependency.
