PROJECT / OVERVIEW

Build the cloud. Learn what keeps it running.

SimuNet lets you learn how cloud systems work through hands-on activities. Start with an empty data center, add equipment, launch a website, and respond to problems.

01 / MISSION

Learn by doing

See how computers, networks, storage, backup, and security work together.

02 / WHAT YOU BUILD

Your equipment

  • Server racks and computers
  • Cooling and backup power
  • Website, database, storage, backup, and sign-in systems
  • Firewalls and recovery systems

03 / CORE OBJECTIVES

Operational skills

  • Spot limited resources
  • Keep a service running
  • Check whether systems are healthy
  • Recognize and reduce security risks
