# Contributing to Simunet

Thank you for helping improve the Cloud Computing Simulator.

## Getting Started

1. Fork the repository.
2. Create a branch for one focused change.
3. Open `index.html` in a browser or serve the project locally.
4. Test the affected UI and JavaScript behavior.
5. Submit a pull request with a clear description.

Example local server:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## What to Contribute

Useful contributions include:

- Cloud infrastructure features
- Cybersecurity demonstrations
- Bug fixes
- Accessibility improvements
- Responsive design fixes
- Documentation and educational content
- Tests and validation

## Development Guidelines

- Keep changes focused and easy to review.
- Use existing HTML, CSS, and JavaScript patterns.
- Preserve keyboard and mobile usability.
- Do not add secrets or generated credentials.
- Explain complex simulation logic with short comments.
- Test rack creation, server installation, deployment, backups, and attacks.

## Pull Requests

Before submitting:

- Verify that `script.js` passes `node --check script.js`.
- Verify that pages load without missing CSS or JavaScript.
- Describe what changed and why.
- Include screenshots for visual changes.
- Link any related issue.

Be respectful during reviews and keep discussions focused on improving the project.
