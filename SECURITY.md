# Security Policy

## Supported Versions

The `main` branch is the only actively maintained version of Simunet.

## Reporting a Vulnerability

Do not publish sensitive security details in public issues or pull requests.

Please report vulnerabilities privately through GitHub Security Advisories:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Create a **New draft security advisory**.

Include:

- A description of the issue
- Steps to reproduce it
- The affected file or behavior
- Any possible impact
- Suggested remediation, if available

Maintainers will acknowledge reports when possible and coordinate a fix and disclosure timeline.
